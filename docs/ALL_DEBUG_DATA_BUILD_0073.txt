ROOT CAUSE ANALYSIS:
1. Arithmetic decomposition of the unaligned completion:
   461 bytes = (7 * 64 bytes) + 13 bytes!
   3981 bytes = (62 * 64 bytes) + 13 bytes!
   In both cases, exactly 1 packet of sector data (64 bytes) was missing when the 13-byte CSW packet
   was transmitted on Endpoint 1 (Bulk IN).
2. The active Data URB swallowed the 13-byte CSW packet directly from Endpoint 1, concluding as a
   Short Packet Transfer (since 13 < 64 = wMaxPacketSize).
3. The host usb-storage driver subsequently submitted a CSW URB for 13 bytes, which hung because EP1
   had no remaining data in the FIFO.
