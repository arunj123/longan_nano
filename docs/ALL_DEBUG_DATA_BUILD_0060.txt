  8. TECHNICAL FINDINGS & BUILD 0061 REMEDIATION PLAN

A. PROVEN HARDWARE BEHAVIOR (BUILD 0060 TELEMETRY):
--------------------------------------------------
1. Hardware Multi-Packet Transfers:
   In the 256-entry register trace, each 512-byte sector is configured in DIEPLEN as
   pcnt=8, tlen=0 (all 512 bytes committed to FIFO 1).
   The Synopsys DWC2 hardware core autonomously sends all 8 packets of 64 bytes with
   DATA0/DATA1 alternating on every packet.
   The total bus time per 512-byte sector was measured between 412 us and 472 us.
   Zero FIFO underrun flags (DIEPINTF_TXFUD) occurred across all 217 transferred sectors.

2. Consecutive 4096-Byte Transfers:
   In trace_live.bin, commands Tag 0x61, 0x62, 0x64, 0x65, 0x66 each successfully read
   and sent 8 consecutive sectors (512 bytes each, 64 total packets per read command).
   Each command concluded with a 13-byte CSW (residue=0, status=0 CMD_PASSED).

3. CSW Framing Timing:
   The 2,500 us framing guard before transmitting CSW guarantees that the Linux xHCI
   host controller completes its Data IN URB retirement before the CSW IN packet arrives,
   completely preventing packet collisions and CSW residue corruption.

B. ROOT CAUSE OF ERROR RECOVERY HANG:
-------------------------------------
1. Bulk-OUT CLEAR_FEATURE Trap:
   In msc_core.cpp::req_handler:
       if ((ep & 0x80) == 0) { // Bulk OUT
           pcore->regs.er_out[EP_ID(ep)]->DOEPCTL |= DEPCTL_SD0PID | DEPCTL_SNAK;
       }
   When the Linux host resets endpoint 1 OUT, it issues CLEAR_FEATURE(ENDPOINT_HALT).
   Setting DEPCTL_SNAK halts OUT reception. Because usbd_ep_recev() was not immediately
   called to re-arm the endpoint, EP1 OUT permanently NAKs all subsequent CBW packets.
   After 10 seconds, the host kernel aborts with -104 ECONNRESET / DID_TIME_OUT.

2. Inter-Sector IN Token Timing during Superblock Read (LBA 1024):
   Reading LBA 1024 from the MicroSD card takes ~1.8 ms.
   While msc_disk_read() is busy, the host issues IN tokens.
   EP1 IN must maintain clean NAK status (DEPCTL_SNAK) and must not allow
   premature transmission or register state corruption while the SD transfer is active.

C. BUILD 0061 REMEDIATION ACTIONS:
----------------------------------
1. In req_handler (msc_core.cpp):
   When CLEAR_FEATURE is received for Bulk OUT (ep == 0x01):
     pcore->regs.er_out[EP_ID(ep)]->DOEPCTL =
         (pcore->regs.er_out[EP_ID(ep)]->DOEPCTL & ~(DEPCTL_STALL | DEPCTL_SNAK))
         | DEPCTL_SD0PID | DEPCTL_CNAK;
     usbd_ep_recev(pcore, MSC_OUT_EP, ctx.cbw_buf, BBB_CBW_LENGTH);
   This ensures EP1 OUT is immediately listening for the next CBW without stalling.

2. In msc_process_read (msc_core.cpp):
   Ensure EP1 IN explicitly asserts DEPCTL_SNAK prior to initiating msc_disk_read(),
   preventing any spurious packet starts while SPI data is being fetched.

3. Bump PID to 0xAB2D and Serial to LNMSC0000061 to provide a clean xHCI port state.
