7. INDEPENDENT ROOT CAUSE ANALYSIS & DIAGNOSTIC FINDINGS
================================================================================

1. Native 512-Byte Sector Transfers Function Perfectly in Silicon:
   - DWC2 autonomous hardware packetization cleanly handles all 8 packets (512 bytes)
     per sector under a single transfer initiation (DIEPLEN PCNT=8, TLEN=512).
   - Data PIDs alternate flawlessly: every sector begins with DATA0, alternates
     smoothly through all 8 packets, and completes with an interrupt only once per sector.
   - Tag 0x60 (LBA 560, 4096 bytes / 8 sectors) and Tag 0x0E (LBA 0, 4096 bytes / 8 sectors)
     demonstrated 100% data transmission with zero packet drops.

2. Discovered Fault 1: CLEAR_FEATURE(0x01) Unconditional SNAK without Re-Arm:
   - When Linux error recovery issues CLEAR_FEATURE(0x01) for Bulk-OUT, msc_core.cpp
     writes DEPCTL_SNAK to DOEPCTL, halting OUT reception.
   - The endpoint is never re-armed with usbd_ep_recev(), causing the device to NAK
     subsequent CBWs indefinitely (observed in Tag 0x65, timed out after 10 seconds).

3. Discovered Fault 2: Destructive ep1_in_hard_reset() Register Clobbering:
   - In msc_core.cpp, ep1_in_hard_reset() sets DIEPCTL = 0U when EPEN == 0.
   - This clears critical configuration bits: EPACT (active), MPL (64 bytes),
     EPTYPE (Bulk), and TXFNUM (FIFO 1), corrupting endpoint 1 until board reset.
